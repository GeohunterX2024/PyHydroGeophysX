# 界面中文化与字体（M4.1、M4.2）

## 语言

- 默认跟随系统：系统语言为中文时显示简体中文，否则显示英文。
- “视图 > 语言”可选“跟随系统 / English / 简体中文”，下次启动生效（设置保存在 QSettings `ui/language`）。
- 翻译在启动时由 `PyHydroGeophysX/qt_apps/i18n.py` 的 `install_translator` 载入，同时载入 Qt 自带的中文翻译（标准对话框按钮等）。

## 翻译范围

- own 目录（`qt_apps/`）中构建界面的文件：按钮、标签、提示、菜单、页签、表单、消息框、文件对话框标题、图件坐标轴与标题、导航树与页面标题。
- 有意保持英文的内容：
  - 日志（便于排查与技术支持）。
  - 不带 data 参数的下拉框条目，以及 `setCurrentText`/`findText` 查找用的文字。代码会把这些文字当作取值读回，翻译会改变行为。
  - 不依赖 Qt 的记录与报告模块（如 `ert_records.py`）。
  - 语言菜单中各语言的自称。

## 代码约定

- 字面量：`QCoreApplication.translate("PHGX", "Load data")`；带变量的写成 `QCoreApplication.translate("PHGX", "Loaded {0} files").format(n)`。这是 `pyside6-lupdate` 能提取的形式。
- 变量中的文字：`i18n.tr(text)`。只翻译字符串，其他对象原样返回。
- 按显示文字比较时，比较的一方也要经过翻译，例如 `button.text() == i18n.tr("Refresh")`。
- 需要保持原样的行，在行尾加 `# i18n: as written`。

## 维护流程

```
python tools/yuem/i18n.py scan      # 列出尚未可翻译的界面文字
python tools/yuem/i18n.py wrap      # 自动改写为可翻译形式（保留原有换行与注释）
# 在 PyHydroGeophysX/qt_apps/translations/zh_CN.json 中补充译文（英文原文 -> 中文）
python tools/yuem/i18n.py catalog   # lupdate 生成 phgx_zh_CN.ts，填入译文，lrelease 编译 .qm
python tools/yuem/i18n.py check     # 门禁：全部可翻译、全部已翻译、占位符一致
```

译文规则：占位符 `{0}`、`{1:.2f}` 原样保留；HTML 标签原样保留；菜单加速键写作“文件(&F)”；仅表示英文复数 "s" 的占位符可以省略，须在 `tools/yuem/i18n.py` 的 `PLURAL_SUFFIXES` 中登记。

## 字体

- 界面字体依次回退：PingFang SC → Hiragino Sans GB → Microsoft YaHei → Noto Sans CJK SC → Segoe UI → Helvetica Neue / Arial / DejaVu Sans。样式表与 `QFont` 只列出本机已安装的字体，自检不再出现 “missing font family” 警告。
- Matplotlib 图件同步使用中文字体（PingFang SC、Hiragino Sans GB、黑体等中第一个可用者），并关闭 unicode 负号，避免负号显示为方框。

## 测试

- `tests/yuem/test_i18n.py`：覆盖与译文完整性、改写工具行为、中文翻译生效。
- `tests/yuem/gui/test_pages.py`：在中文翻译下逐页构建，任何译文模板错误都会在此暴露；启动自检无字体警告。
