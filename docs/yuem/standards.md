# 规范对标（M4.6）

本文列出 PyHydroGeophysX 各方法的处理与反演参数对应的行业规程，供工程技术人员在设计、质控与报告中查阅依据。规程的编号、名称与现行状态已于 2026-10-31 在国家标准馆、全国标准信息公共服务平台核对。

**说明**：规程规定的是设计、采集、处理与成果报告的技术要求。软件参数的默认值是 PHGX 自己的取值，并非摘自规程。具体限差（如观测精度、重复观测误差、质量评价等级）以规程原文为准，项目中请按适用规程与合同要求设定。

## 二、参数与规程的对应

### ERT / IP（`qt_apps/modules/ert/`，工作流 `ert.single_inversion`、`ert.timelapse_inversion`）

| 软件参数 | 界面位置 | 对应规程与主题 |
|---|---|---|
| 互易误差上限（Reciprocal error） | 数据质控 > 更多检查 | DZ/T 0073-2016、DZ/T 0072-2020：观测精度检查（重复与互易观测） |
| 叠加离散度上限（Stacking spread） | 同上 | DZ/T 0073-2016：观测精度检查 |
| 接地电阻上限（Max contact R） | 同上 | DZ/T 0073-2016、DZ/T 0072-2020：接地条件 |
| 最小测量电压 / 最小供电电流 | 同上 | DZ/T 0073-2016：测量电压与信号强度、供电电流 |
| 误差上限、视电阻率范围 | 数据质控 | DZ/T 0073-2016：资料处理中的数据取舍 |
| 人工剔除（拟断面框选） | 拟断面下方 | DZ/T 0073-2016：资料处理中的数据取舍；剔除记录随数据保存（`docs/yuem/qc.md`） |
| 正则化系数 λ、目标 χ² | 反演 | DZ/T 0073-2016、CJJ/T 7-2017（高密度电阻率法）：资料处理与反演 |
| 极化率、激电相位（IP 数据列） | 数据载入与反演 | DZ/T 0070-2016 |
| 视电阻率拟断面、反演断面图件 | Model Viewer 导出、`visualization/styles` | DZ/T 0073-2016、DZ/T 0072-2020：图件编绘与成果报告 |

### 单位

所有参数与数据集字段的单位取自 `results/units.py` 的注册表，与 DZ/T 0361-2020《地球物理勘查计量单位》对应，例如电阻率 Ω·m（软件内记作 `ohm.m`）、极化率 mV/V、磁感应强度 nT、重力异常 mGal。

## 三、界面中的标注

`qt_apps/standards.py` 登记了上表中带控件的参数（ERT 的质控阈值与反演参数，TEM 的尾部截断、剔除方式与目标 χ²，MT 的误差下限、静态偏移与目标 RMS，重磁的相对误差与噪声下限）。页面构建时，规程编号、名称和对应主题会追加到控件的提示文字中，例如：

> 规程：DZ/T 0073-2016《电阻率剖面法技术规程》；DZ/T 0072-2020《电阻率测深法技术规范》（观测精度检查（重复与互易观测））

GUI 测试 `test_parameters_name_their_standard` 检查每个登记的控件都带有标注。

## 四、维护

- 规程修订后，同步更新 `qt_apps/standards.py` 的 `STANDARDS` 与本文第一节，并在 `CHANGELOG-YUEM.md` 记录。
- 新增参数如有对应规程，在 `ANNOTATIONS` 中登记控件属性名、规程与主题。
